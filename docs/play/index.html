フラグメントを喰らって大きくなり、スフィアで最大の存在になれば次のスフィアへ。 大きな敵の弾は痛いが、弱らせれば体当たりで取り込める。

Devour fragments to grow; become the largest on the sphere to fly on to the next one. Bigger enemies hit hard, but once weakened they can be rammed and devoured.

操作: ←→ / A D で旋回、↑ / W でダッシュ、↓ / S でブレーキ (旋回が速くなる)。 スペース / J L で攻撃 (押したままで連射)、I K / C V B N M で緊急回避 (0.3 秒無敵のバレルロール、3 秒に 1 回)、Esc / P でポーズ、タイトル / ポーズ画面の ↓ でミュート。 ゲームパッド (A / X / Y: 攻撃、B / ショルダー: 回避) とタッチ操作にも対応。

Controls: ← → / A D turn, ↑ / W dash, ↓ / S brake (and turn faster). Space / J / L fire (hold for auto-fire), I / K or C V B N M dodge (a 0.3 s barrel roll that bullets pass through, once every 3 s), Esc / P pause, ↓ on the title or pause screen mutes. Gamepads (A / X / Y fire, B and shoulders dodge) and touch controls work too.

このゲームは組み込み向けグラフィックスライブラリ ShapoGFX のデモとして作られたサンプルアプリケーションです。

This game is a sample application written as a demo of ShapoGFX, a graphics library for embedded systems.
