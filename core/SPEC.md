# Devour Sphere (コアプログラム)

ここではシューティングゲーム「Devour Sphere」のコアプログラムについて説明する。

## コンセプト

プレイヤーはサイバー空間の中に生まれた「生命体」。
その空間ではプレイヤーと同じような生命体が球状の物体「プラネット」の
表面付近に集まって弱肉強食の生態系を形成している。
生命体は、自分と近い大きさ (自分の 2/3～1.5倍) の大きさの他の個体を攻撃できる。
攻撃を受けた生命体は「体力」を奪われ、体力がゼロになると死ぬ。
死んだ生命体は自身を構成したいた「部品」をばらまき、それが他の生命体の餌となる。
餌を食べることで生命体は大きく成長し、より大きな他の個体を攻撃可能になる。
プレイヤーは他の生命体と戦って部品を集めてより巨大化し、
今いるプラネットで最も巨大な生命体となることを目指す。

このゲームは「slither.io」から着想を得ている。

## 部品

生命体の構成要素。
部品には大きさがある。大きさは 1、2、4、8、... と 2 のべき乗の値をとる。
画面上では大きさに比例して「青緑色の正方形の 1 つの頂点を長く引き延ばした盾のような形」として描かれる。

## エネルギー粒子

生命体が攻撃を受けることで奪われた体力はエネルギー粒子となって浮遊する。
画面上では星のような「白い光の点」として描かれる。

## 生命体

部品が集まって意思を持つようになった存在。
プレイヤーも他の生命体と同じ存在であるが、その形状は個体によって異なる。
浮遊している部品に触れて取り込むことでその分巨大化する。
体力ゲージを持ち、生まれた時は満タンだが、攻撃を受けることで体力が減る。
体力はエネルギー粒子に触れて取り込むことで回復する。
体力がゼロになると生命体は死に、部品がバラバラになって浮遊する。
生命体同士が衝突した場合、大きい方が小さい方を取り込む。

### コア

生命体の意識を司り、部品を一つの塊に繋ぎ止める中核。
生命体が死ぬとコアは消滅する。
画面上では白い部品として描かれる。

### 生命体の描画

部品の集まりとして描画する。

生命体は X, Y の 2 次元のローカル座標系を持ち、その中でコアと部品が配置される。
生命体の進行方向を Y 軸、生命体の右方向を X 軸とする。
コアは原点より前方よりに固定されており、尖った頂点を前方に向けている (戦闘機のコックピットのイメージ)。
コアのやや後方に部品が横に広く寄り集まっている (戦闘機の翼のイメージ)。
コアの大きさは生命体自身の大きさ (部品の大きさの合計) に比例し、位置も大きさに比例して前進する (翼に埋もれないように)。

部品の配置は次のように決定する。

- 全ての部品は X 軸の正の方向にだけ存在するが、個々の部品の「分身」が Y 軸を境に反転した位置に存在する。
- コア、部品、部品の分身を含めた全体として生命体は左右対称の見た目になる。
- 体内のコアと部品は、互いの距離の 2 乗に反比例して引力が働き、距離の 3 乗に反比例して斥力が働く。
- 部品の位置はリアルタイムで計算され、浮遊している部品が取り込まれて体内に入ることで有機的に形が変化していく。
- 描画するときは X 軸の位置をやや大きくとり、翼のように横長に広がって見えるようにする。

これにより、コアのやや後方に左右対称に部品が寄り集まった、鳥や飛行機のような形状になる。

個々の部品の向きは、生命体のやや前方もしくはコアを中心として部品の尖った頂点をその反対方向に向けて放射状に配置する。
部品の尖った頂点が後方に向かって開くように配置されるので、より翼っぽくなる。

### 大きな部品の合成

体内で同じ大きさ同士の部品が十分近くまで接近すると合体し、2 倍の大きさの部品となる。

### 他の生命体への攻撃

体力を少しずつ消費して他の生命体を遠距離攻撃できる。
プレイヤーはゲーム開始時に武器を選ぶ。

- バルカン砲: 縦スクロールシューティングゲームのバルカン砲のような弾。威力が小さく弾速も遅いが連射が速く、接近戦に有利。遠くに行くほど広く広がる。
- レーザー: 細長い弾。当たる範囲は狭いが弾速が速く、威力が強い。
- ミサイル: 敵を追尾する弾。自動で近くの敵を追尾するが、威力は弱い。

弾は生命体の大きさに応じて大きく強力になるが、弾速は変わらない。
自分の弾はオレンジで、敵の弾はピンクがかった赤で描かれる。

レベルの低いプラネットでは敵は攻撃してこない。
レベルが上がるにつれてバルカン、ミサイル、レーザーなどを使う敵が現れてくるようになる。

## プラネット

生命体が集まる仮想の星。
プラネット上には最大 1024 個の部品と 256 体の生命体が存在できる。
生命体はプラネットの地表から少し離れた空中を地面と平行に移動する。
それぞれの生命体の位置と進行方向は 3 次元ベクトルで表される。
小さな生命体はより高い位置に、大きな生命体はより低い位置を飛んでいる。
プレイヤーが小さいうちはまだ交戦できない大きな生命体を下に見下ろす形になる。
プレイヤーが交戦可能な敵は本来の色で、交戦できない敵は灰色に描かれる。
プラネット自体はイコソスフィアのワイヤーフレームのように描かれる。
プレイヤーがプラネットに降り立った時点ではさまざまな大きさの生命体が
プラネット上を回遊しており、プレイヤーはその中でかなり小さい方の存在。

プレイヤーがプラネットで最も大きな存在になると
そのプラネットから飛び立ち、新たなプラネットを目指す。
プレイヤーの大きさは画面上では維持されるが、
ゲーム内部ではプレイヤーを小さな存在に戻すことで
より巨大なプラネットに進出したように見える。
(内部で数値が際限なく大きくなってオーバーフローすることを防ぐ意味もある)

## 操作

何も押さなくても前方へ巡航する。
左右キーで左右に旋回。
上キーを押している間体力を消費しながら高速で前進する (ダッシュ)。
下キーを押している間減速し、最終的に停止 (ブレーキ)。
ブレーキを押しながら旋回することでクイックターンができる。
A ボタンで攻撃。押したままで連射。

PC では ↑↓←→ と WASD を方向キーとして使う。
IJKL キーとスペースバーを A ボタンに割り当てる。

## 画面配置

プレイヤーの後方上をカメラがついていく三人称視点。
プレイヤーが左右に旋回するとカメラはやや左右にロールする。
自分の体力ゲージと、今いるプラネット内での自分の大きさの順位が画面隅に表示される。
ダッシュ時はカメラがプレイヤーの後方に近づき、ズームして視界が狭くなる。
ブレーキ時はカメラがやや引いて広角になり、遠くを見渡せる。

## デザイン

黒い背景にワイヤーフレームのプラネット、その上空を単色で原色の生命体や部品が浮遊するサイバネティックな見た目。

## 実装

実装は C++ を使う。
コアプログラムは特定のプラットフォームに依存しないが、組み込み機器で実行することを想定し、
例えば計算量の多い部分は固定小数点化するなどの工夫をする。
描画周りは ShapoGFX (submodule/shapo-gfx/) を使う想定。

include/devoursphere にはアプリケーション実装側へ公開するヘッダファイルが置かれる。
src/ にはコアプログラムの実装が置かれる。
